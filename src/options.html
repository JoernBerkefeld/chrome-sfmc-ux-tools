Theme of the code editor

Replaces the themes of Marketing Cloud's own menu.

Menu of the code editor (right-click and gear button)

Changes apply at once; open editors need no reload.

Format on save

Applies to the Save and Save and Exit buttons and to Ctrl+S / Cmd+S in the code editor. Format at any time with Shift+Alt+F or the { } button of the editor.

Readable keys

Applies to new automations and to the dialogs that create an SQL query, script, filter, import, data extract or file transfer activity in Automation Studio, and to new data extensions in Contact Builder and Email Studio, to new journeys and API events in Journey Builder, and to new sender profiles, send classifications, delivery profiles, file locations, roles and users in Setup. Spaces become underscores, special characters are left out. A key you type yourself is kept.

Journey names

Journey Builder gives every new journey that name, and hands it on to the journey's API event.

Saved logins on Setup's user pages

Without this, a browser's password manager takes the page for a login form and fills a saved username and password into the user you are creating or editing, and into its external key.
